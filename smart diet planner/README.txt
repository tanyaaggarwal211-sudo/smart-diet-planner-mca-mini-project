SMART DIET PLANNER - JAVASCRIPT VERSION

Files:
- index.html       Home page
- myPlan.html      Diet plan form
- foodGuide.html   Searchable food guide
- track.html       Daily progress tracker
- style.css, myplan.css, foodGuide.css, track.css
- script.js        JavaScript for all pages

How to run:
1. Extract this ZIP file.
2. Keep all files in the same folder.
3. Open index.html in a browser (or use Live Server in VS Code).
4. Use the navigation links to open Plan, Food Guide and Track.

Basic JavaScript features:
1. Home page button navigation.
2. Form validation and a simple diet suggestion.
3. BMI calculation for general information.
4. Food guide live search.
5. Add/reset water glasses.
6. Add/reset activity minutes.
7. Meal checkbox progress.
8. localStorage saves the profile and tracker values in the same browser.

Note:
- This is a front-end learning project. It does not use a server or database.
- Saved values are stored in the browser using localStorage.
- The plan is educational only and is not a medical diet prescription.
- The original food image file was not among the uploaded files. If you have it, place it in this folder using the same filename referenced in index.html.
